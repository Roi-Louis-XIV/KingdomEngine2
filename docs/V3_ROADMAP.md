# Feuille de route V3

1. **Fondation connectée — jalon livré dans cette branche.** React/TypeScript, identité visuelle minérale, navigation à six espaces, monde global, tableau de bord réel, bibliothèque, premier éditeur pleine page et cycle de sauvegarde/publication SQLite. Les panneaux modules/interface/relations exposent les données conservées ; ce jalon n'est pas le Studio no-code complet.
2. **Éditeurs de primitives génériques.** Objets/consommables, stocks et commerce, métier, recettes, postes, dialogues et références typées. Réutiliser les APIs existantes et préciser les contrats manquants avant de les compléter. Étendre les tests métier sans contenu d'univers codé en dur.
3. **Éditeur Discord.** Vérifier les limites officielles Components V2 actuelles ; créer l'arbre, le rendu approximatif PC/mobile et l'inspecteur synchronisé. Édition/duplication/réordonnancement accessibles ; aucune limite artificielle de six pages. Migrer les anciens composants sans perdre leur contenu.
4. **Règles et simulation.** Déclencheurs/conditions/actions atomiques, diagnostics explicables, listes dynamiques et graphe de dépendances. Profils de test isolés, temps simulé, concurrence à deux joueurs, état « simulé » explicite.
5. **Recette Taverne V11.** Depuis un bâtiment vide, créer intégralement les entités et écrans dans le Studio ; livraison → prix dynamique → cuisson → récupération → achat → énergie → dialogue conditionnel. Vérifier démission/XP 80–20, timer réel, récupération unique et bonus expirables.
6. **Validation Discord et migration produit.** Monde de test autorisé, données isolées, panneaux mono-message et mobile, workers/audio, reprise après redémarrage, publication sans perte. Déploiement et fusion uniquement après autorisation explicite.

Les corrections V2 identifiées par les tests sont suivies dans `V3_PROGRESS.md` et ne sont pas dissimulées par des tests désactivés.
